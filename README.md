# Отношение к астрологии пользователей дейтинг-приложения OKCupid в зависимости от пола 
### Мы предполагаем, что больший интерес к знакам зодиака наблюдается у женщин. Заодно мы проверяем распределение мужчин и женщин в приложении, а также смотрим распределение пользователей по полу и возрасту.
